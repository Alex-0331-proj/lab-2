# Лабораторна робота №2: Web-дизайн

Тема:Створення клієнтських Web-додатків засобами мови JavaScript (ShortyURL)

завдання
Розробити функціональність для статик-сторінок за допомогою патерну MVC та WebWorkers.

Технології
- JavaScript (ES6+): класи, модулі, Proxy
- WebWorkers: фонова генерація посилань
- Bootstrap 5: адаптивна верстка та модальні вікна.
- LocalStorage: збереження даних клієнта
